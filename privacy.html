NBA Forecasting Recovery

Privacy notice

Last updated: 14 October 2026.

NBA Forecasting Recovery is a private tool operated by its owner for backup and recovery of an NBA analytics project.

Google data used by the application

The recovery connection requests Google Drive access limited to files authorized for this application. It uses the selected recovery folder’s identifier and metadata, file metadata, and recovery-file contents to create, verify, download and restore project recovery copies. It does not request access to Gmail, contacts or calendars.

The private dashboard also uses Google sign-in and the owner’s Google account identity to control access. Google handles the sign-in process; the application does not collect a Google password.

Purpose and storage

Google data is used to provide private backup, recovery and access control. Recovery copies contain project working data, public NBA source evidence, saved model and preview files, and operating files. Copies are stored in the owner’s selected private Google Drive folder and private Google Cloud project storage.

Authorization credentials are stored separately on the owner’s computer and in the private cloud secret store needed for the recovery worker. Credentials are excluded from recovery copies and this information website.

Access and sharing

The application does not sell Google user data or use it for advertising. It does not use Google user data to train an AI model. Access is restricted to the owner and the application’s dedicated cloud identities. Google provides the hosting, authorization and storage services and processes the information needed to operate them.

Retention and the owner’s controls

The owner controls the recovery copies and their retention. Stopping an automated test does not delete existing recovery files. The owner can delete copies from Drive and Cloud Storage, remove saved credentials, and revoke the application’s connection in the Google account’s third-party connection settings. Revocation prevents future authorization refresh; an already issued access token can remain valid until it expires. Provider retention and account policies also apply.

This information website

This website has no sign-in form, application cookies, advertising or analytics scripts. If published on GitHub Pages, GitHub logs visitor IP addresses for security under its privacy statement.
