NBA Forecasting Recovery

A private backup and recovery tool for a single-owner NBA analytics project.

The recovery tool uses Google authorization to save and read recovery copies in a Google Drive folder selected by its owner. Those copies preserve the project’s working data, saved evidence and operating files so the owner can restore the project.

The private dashboard uses Google sign-in to restrict access to its owner. This website explains the application and its data practices; it does not provide access to the dashboard or any backup files.

Read the privacy notice for details about Google data, storage and access controls.
